Status (2026-11-18): the Pinterest account, claim and boards are NEEDS-YOU / not yet done. Pin images are COMPLETED and checked (24 pins at 1000x1500, one per public guide, each built from that guide's own hero photo). Strategy and rules: docs/PINTEREST-STRATEGY.md.

## Keeping this list current (one command per new article)

1. Publish the guide (it is public only when it passes the publish rule in src/content/publish-rule.ts).
2. `python3 scripts/make-share-images.py` makes its pin and share image and deletes images of retired or unpublished guides (`--check` only reports).
3. `python3 scripts/make-pin-sheet.py` rewrites docs/pinterest-pins.csv (image URL, title, description, destination with tracking, board). Titles and descriptions are copied from guide metadata, so no claims are invented. A guide missing from the board map in the script gets a default board and a NOTE on screen.
4. Paste the new row into Pinterest (or give the CSV to Cowork). Vitest fails if a public guide has no pin, a stale pin exists, or the CSV is out of date in structure.

## Tracking parameters (UTM)

Every pin destination is the guide address plus `?utm_source=pinterest&utm_medium=social&utm_campaign=<board-slug>&utm_content=<pin-slug>`; the campaign is the board name as a slug (for example `vacation-rental-planning`) and the content is the guide slug. GA4 reads these automatically, so Pinterest sessions show under Traffic acquisition with source "pinterest". Use only these four parameters, lowercase, never on internal links.

The site is safe with query parameters (VERIFIED in code, 2026-11-18): the canonical link and og:url are built from the page path only (src/lib/seo.ts, `pageHead`), so a tagged URL canonicalizes to the clean one; the sitemap lists clean paths (src/lib/sitemap-entries.ts); routes ignore unknown query strings. A tagged URL opened in a browser was not tested on production (nothing is deployed yet; BLOCKED until the bulk merge): after deploy, open one tagged URL and confirm the page loads and the canonical is the clean address.
