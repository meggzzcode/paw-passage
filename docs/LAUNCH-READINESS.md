# Launch readiness

Reviewed against the current code. "Verified" means a local automated test or a static read, never a live service. No real charge, account, device or deploy was used. Nothing here claims a real-device or real-checkout result. Results of the final code run belong in the **Last verified run** section of `QA-REPORT.md`; this file states no test counts.

## Verdict: BUILD COMPLETE — EXTERNAL SETUP REQUIRED

Provisional; the lead confirms the final verdict. The commercial code paths behave correctly against fakes. No repository defect is known. Launch needs owner and Cowork work that cannot be done locally (`COWORK-HANDOFF.md`).

### What blocks launch (all external)

1. **Netlify has not been exercised.** A clean local build with the Netlify preset succeeds (static files in `dist/`, server in `.netlify/functions-internal/server`), but a real preview deploy has never run: `/api/*` routing to the Function, redirect and header application, environment isolation, blob behavior and cost are unverified (A1 to A5, B2 to B8).
2. **Gumroad contract UNVERIFIED (A7, E4).** Endpoint, parameters and the response fields `success`, `purchase.id`, `refunded`, `chargebacked`, `disputed`, `dispute_won`, `license_disabled` are from documentation shape, not a real key. If any is wrong, activation fails closed (503 or 403): nobody is wrongly granted access, but a wrong field on re-check could revoke a paying customer, so E4 and E7 matter.
3. **No premium library is in any store yet (B8, F3).** Until it is imported, the paid product, showcase previews and public counts have no data (previews fall back to an honest empty answer).
4. **No real-device QA (C2, C3, C6).**
5. **Owner administrative decisions and Gumroad setup (D1 to D4, E1 to E3).**

Not blockers: Google Analytics delivery (C11), gift checkout (E8), PWA and notifications (paused; `PWA_ENABLED=false`, `flags.notifications=false`, no scheduled function).

## Environment variables (names only)

Netlify Functions scope: `SESSION_SECRET` (32+ chars), `PP_DATA_KEY` (set once, never change), `GUMROAD_PRODUCT_ID`. Preview and dev only: `PP_ALLOW_TEST_PROVIDER`. Build scope (public): `VITE_CHECKOUT_URL`. Optional notifications: `NOTIFICATIONS_ENABLED`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` (secret), `VAPID_SUBJECT`. Owner terminal only: `NETLIFY_AUTH_TOKEN`, `SITE_ID`. There is no `PP_ENV`; the store is chosen from the deploy context. The notification variables matter only if push is ever resumed; see `NOTIFICATIONS.md`. Also `SHOW_DRAFTS` (preview deploys only; never on production).

## What a nontechnical buyer needs

A GitHub account (repository transfer), a Netlify account (site transfer), the domain registrar login, a Gumroad account or a plan to re-list the product, Pages CMS sign-in with their own GitHub account, the protected premium package and a dated backup (handed over outside the repository), the three secrets re-created at closing, and `OPERATIONS.md` plus `TRANSFER-INVENTORY.md`. Everyday editing is Pages CMS for guides, collections and settings. Premium changes need a person comfortable running two terminal scripts, so a buyer without that skill needs a short paid handover session.

## Decisions needing owner approval

The full table with options is in `COWORK-HANDOFF.md` (Owner decisions OD1 to OD12). The ones that shape readiness:

1. The protected premium package is kept outside this repository; the owner confirms its safe storage.
2. Accept up to about 24 hours between a refund or chargeback and loss of access (no webhook), or pay for a webhook design later.
3. A license key is not limited to one device or person (restore works from any device; `increment_uses_count=false`). Accept key-sharing risk, or set a use limit once the Gumroad contract is read.
4. Keep PWA install prompts and notifications off at launch and revisit after the first month of real credit usage.
5. Cookie consent approach, support mailbox, refund period on Gumroad, deletion-request policy.
6. Slogan: the tagline is "A lifetime of little adventures."; the retired signature line stays out of the hero and H1 with its guard test, unless the owner says otherwise.
