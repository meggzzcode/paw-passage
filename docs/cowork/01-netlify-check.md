# Cowork prompt 01: Netlify plan check, badge and notifications

Use after reading step 1 of docs/OWNER-WALKTHROUGH.md. Paste everything below the line into Cowork.

---

You are helping me check my Netlify account for my website pawsandpassage.com. I am signed in at https://app.netlify.com.

## Rules (read first, apply to every step)

- Work only in my own browser, in tabs I already have signed in. If a page asks me to sign in, STOP and tell me; I will sign in myself.
- NEVER type, paste, read aloud or store any password, one-time code, recovery code, security question, payment card, bank, tax, SSN or PayPal detail.
- NEVER buy, upgrade, start a trial, change a plan, or accept any agreement, terms box, or "authorize"/"allow access" request that I did not name below. If any such prompt appears: STOP, take no action, and describe it to me.
- STOP and tell me on any CAPTCHA, "verify it is you", security warning, suspicious-activity notice, unexpected popup, or a screen that does not match these instructions. Do not try to work around it.
- Menu names may differ slightly from this text. If you cannot find an item after two tries, use the nearest equivalent only if it is clearly the same setting; otherwise stop and report it as "not found".
- Change only what is named. Do not delete, remove, disconnect or invite anything.
- At the end, give a short results table (item, what you saw, what you did, status: done / already done / blocked / skipped) and list anything unexpected.

## Steps

1. Open the Usage & billing area for my team (team menu, then Usage & billing, then Plan details). READ ONLY. Report the plan name, whether monthly credits are shown (credit-based) or usage packages (legacy), the credits used this month and the cycle reset date. Do not click Upgrade, Change plan, Add credits or anything with a price.
2. Open the site's project, then Project configuration, General, "Powered by Netlify badge". Report whether the setting is on or off and whether it is locked ("upgrade to turn off"). If it is NOT locked and is on, switch it off and click Save. If it is locked, do nothing and report the exact text shown. Do not follow any upgrade link.
3. Open Project configuration, Notifications, Deploy notifications. Report which notifications exist (type and event). Do not add Email (it needs a paid plan). If there is no GitHub commit status entry for "Deploy failed", tell me; do not add anything unless I say so.
4. Open https://www.pawsandpassage.com in a private/incognito window, wait 5 seconds and report whether a dark "Powered by Netlify" pill appears at the bottom right.

Report table: plan name; credit-based or legacy; credits used; badge state before and after; locked or not; notification list; private-window result.
