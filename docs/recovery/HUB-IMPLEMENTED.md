# Travel essentials hub: what was built (2026-11-18, extended by WP4)

Implements the safe subset of docs/recovery/10-travel-essentials-hub-spec.md and Task B of docs/recovery/07-analytics-affiliate-system-automation.md.

## Built
- **content/products.yml**: central records for the existing 25 products (generated by scripts/migrate-gear-to-yaml.ts from src/content/gear/*.ts, no URL typed by hand). Fields: id, name, brand, categories, summary, keySpecs, specSource, manufacturerUrl, retailerUrl, retailerName, lastVerified, active, affiliateId. `lastVerified` = the existing `specSource.accessedOn` date. `retailerUrl` and `affiliateId` are empty for all products (none exist in the repo).
- **Loader**: src/content/products-schema.ts (strict zod; no price/rating/commission keys), loaded in plugins/content.ts like affiliates.yml (checks duplicate ids, that `affiliateId` exists in affiliates.yml and is not a stay link), exposed as `virtual:content` `products`. src/content/gear.ts now reads it; an inactive product is not returned by `getProduct`.
- **Pages CMS**: new "Products (travel essentials)" file in .pages.yml.
- **Link helper**: src/content/gear-links.ts `resolveProductLink` (approved affiliate, never a stay link, then manufacturer, then plain retailer, then none) and `relFor` (affiliate "sponsored nofollow noopener", plain "nofollow noopener", never noreferrer). Used by the hub only. GearPicks and PackingBuilder still use `productButton` (unchanged; identical results today).
- **Pages**: /gear and /gear/<category> (src/routes/gear.index.tsx, gear.$category.tsx), src/components/site/GearHubCards.tsx (photo-less cards, "Researched, not tested by us", last verified date, "How we pick" block linking /methodology, /editorial-standards, /corrections, disclosure shown only when an approved affiliate link renders, with a visible "Affiliate link" label next to such buttons). Card trade-offs ("Check before you buy") come from the guide that already features the product.
- **Live categories** (3+ active products): road-trips, cabin-vacations, large-dogs, travel-safety, feeding-and-hydration, travel-comfort. Not shown (0 or too few products, unknown category = 404): beach-vacations, senior-dogs, multiple-dogs.
- **Navigation**: "Gear" in header (between Guides and Tools) and footer Explore; footer About adds Methodology and Corrections; homepage "Travel essentials" section (3 tiles). All gated on `hasGear()`.
- **Sitemap**: /gear, live category pages, /methodology, /corrections.
- **SEO**: pageHead titles/descriptions with no brand names, BreadcrumbList only, no ratings/offers JSON-LD, no ItemList. No hero or share photo (no honest match; falls back to the default share image).
- **src/routeTree.gen.ts** regenerated (includes the other worker's /methodology and /corrections routes) and the react-start Register block kept.
- **Tests**: src/test/gear-parity.test.ts (TEMPORARY: outbound URLs and facts identical to the legacy TS; delete with src/content/gear/*.ts once accepted), src/test/gear-hub.test.tsx (data, fallback order, rel, disclosure, routes, 404s, meta, sitemap, CMS form).
