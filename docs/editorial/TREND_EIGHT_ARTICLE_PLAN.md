## Appendix B. Method for computed figures

Guide inventory: a Node script parsed YAML frontmatter of `content/guides/*.md` (package `yaml`) and regex-parsed `src/content/guides/*.ts`; words = `[A-Za-z0-9'-]+` tokens in the body after removing `{{...}}` directives and link URLs. Keyword counts used case-insensitive regexes over the body (winter, boots/salt/de-ice, RV/camper/campground, crash/CPS/certif, enrichment words, gift, Smokies town names, fenced, multi-dog terms, restraint words). Dataset: Python read `public/pet-policies-38-managers.csv` with `csv.DictReader`; "fee stated" = `pet_fee_as_stated` not "Not stated"; "zero" = starts with `$0`; fee wording by substring (per night; per pet / per animal / per dog / first / each; per stay / one time / per week; clean / flea); "limit stated" = `dog_or_pet_limit` not "not stated"; weight, crate and Smokies subsets by column filters. Two-dog totals multiply the stated per-pet amount by two (tiered managers add first and second), before tax, using the lower tier where a weight tier exists; they are arithmetic on stated figures, not quotes. Product status: `content/products.yml` parsed and joined to approved non-stay entries in `content/affiliates.yml` by `affiliateId ?? id`, as `resolveProductLink` does. All scripts were run from the repository root; they are not committed.
