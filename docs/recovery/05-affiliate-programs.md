## 4. Policy-compliance checklist for our link architecture
Evidence read: `src/content/affiliates.ts` (approved gating, `AMAZON_DISCLOSURE`), `src/components/site/Markdown.tsx:18-25` (aff: links render the stored URL with `rel="sponsored nofollow noopener"` only when approved), `src/components/site/GearPicks.tsx:49` (affiliate button rel includes sponsored nofollow noopener), `content/affiliates.yml` (10 approved Vrbo links, `kind: stay`).

- [x] Links are unedited stored URLs, no redirect or cloaking (Expedia 11.1.1/16.2/16.3; Amazon no-cloak). Do not add UTM or parameters to stored URLs.
- [x] No prices or coupons shown (Amazon prices rule; Expedia 11.3, 11.4; PetSafe/Chewy coupons). Keep it that way when adding Amazon.
- [ ] Amazon links must contain the assigned tag and sit on the registered site only; put "Amazon" in `network` so `isAmazon()` triggers the exact disclosure sentence.
- [ ] Add the disclosure near every affiliate group (Amazon sentence exact, "I earn..." wording; do not change "I" to "we" per code comment).
- [ ] Meta tags/titles: Expedia 12.3 bars Marks in meta tags. Airbnb vs Vrbo guide title flagged earlier; review before wider use.
- [ ] Product photos: Amazon barred from using its images except via its tools; `docs/PRODUCT-PHOTOS.md` should confirm photos come from makers with permission, not Amazon.
- [ ] Brand rules per program once approved: PetSafe (no bidding on trademarks, no content competing with Kurgo/Invisible Fence/Premier Pet/SportDOG, no negative language per [3P]), Orvis (no direct linking if approved), Kurgo Affiliate Guide.
- [ ] Do not run paid search on any brand name; none of the programs above permit trademark bidding where stated.
- [ ] Keep "approved" false until the network says approved; keep `productLinkId` consistency fix from `AFFILIATE-OPPORTUNITIES.md` (GearPicks vs affiliate-usage).
- [ ] Privacy/disclosure pages must cover each added network's cookies (Expedia 9.1.2 already; extend per program).
