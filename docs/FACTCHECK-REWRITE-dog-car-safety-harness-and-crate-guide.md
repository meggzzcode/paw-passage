## The CPS conflict, settled
The car-safety guide cites CPS listing pages (110 lb Clickit Range test dog, November 2024, and others). The two-large-dogs ledger said those CPS pages "returned empty" on 2026-11-18. Both statements describe real observations, but only the first is about the content. The WebFetch summariser returns an empty result for centerforpetsafety.org pages (it did so again today), while the plain HTML loads with full text (HTTP 200). Read today: Clickit Range (Small to X-Large, November 2024, CPS-001-014.01, 110 lb, 5 star), Saker Bomber (X-Small to Large, November 2022, 75 lb), Atom (one size, August 2024, 12 lb), Gunner Medium (March 2017, 45 lb) and Intermediate (June 2015, 75 lb), Lucky Duck Large (July 2022, 110 lb, Lucky Ratchet Strap Kit). All match the car guide's table and picks. The two-large-dogs guide cites none of these pages, so its text stands; its ledger note was corrected.

One CPS claim could not be supported and was reattributed: the Atom "also appears in the CPS Certified directory". The directory page in plain HTML lists only crates and carriers (Gunner, Lucky, Cabela's, PawsInCar, Away), with no harnesses, no Atom, and no weights or dates. The Atom claim now cites the Atom listing page itself.
