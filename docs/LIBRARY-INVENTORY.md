# Library inventory

Computed by `node scripts/library-stats.mjs` (add `--json` or `--md`). The counts below are the FULL-mode figures: they need the premium folder (`PREMIUM_DIR=<package>/adventures`, or `--premium-dir`). Without it the script runs in a labelled free-only (partial) mode and premium counts read 0. The script is read-only, validates every card with the real schema, and prints only counts and card ids, never premium text. `src/test/library-inventory.test.ts` runs it and checks the numbers agree with each other. Re-run it before quoting any number in copy. Last run: **2026-11-27** (against protected package `premium-2026-11-26-4`).

## Collection Complete (curated collections only)

The award needs a curated collection with **three or more** cards, all completed (`achievements()` in `src/passport/progress.ts`; the Passport page already says "three or more"). It is judged against the whole collection, so it only counts once the full library is loaded for an entitled customer. Before package `-4` 22 of the 25 curated collections qualified; the three that did not are listed in the findings above. With `-3` all 25 qualify. Memberships were only added, never removed, so no earned progress can be lost (none of the three thin collections could have been completed before).
