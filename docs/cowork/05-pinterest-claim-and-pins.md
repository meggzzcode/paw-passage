- Menu names may differ slightly from this text. If you cannot find an item after two tries, use the nearest equivalent only if it is clearly the same setting; otherwise stop and report it as "not found".

## Steps

Do NOT click Verify yet. When I tell you the tag is on the site, return to this screen, enter https://www.pawsandpassage.com and click Verify, then report the result.
3. Profile. Set only if empty: Display name "Paws & Passage"; About: "Researched guides and tools for renting a vacation home with your dog: pet fees, dog limits, fences and what to ask the host."; Website https://www.pawsandpassage.com. Do not change the profile picture; tell me if it is empty.

5. Pins. For each row in the table below: create a Pin from the image at the Pin image URL (open it in a tab, save the image, upload it), set the Title and Description exactly as written, the Destination link exactly as written (it already has tracking parameters: do not edit, shorten or replace it; no affiliate links), and the Board. Publish the first 3 now and schedule the rest at 3 per day at different times. Pinterest allows at most 10 scheduled pins at once and 30 days ahead, so schedule in rounds and tell me what is left. After each pin confirm it saved and the link opens the right guide. If Pinterest blocks a pin or link, skip it, note why and continue.
6. Report: a table of each pin, board, status (published or scheduled date) and any Pinterest warning; the meta tag from step 2; whether Rich Pins validation is offered for the site (change nothing); anything that needs me.
