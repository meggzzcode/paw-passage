# Self-hosted fonts: licences and sources (2026-11-18)

Both families are licensed under the SIL Open Font License 1.1 (OFL), which allows self-hosting, embedding on websites and commercial use. The OFL text is kept next to the font files in `public/fonts/` (the licence requires it to travel with the fonts).

| Family | Licence | Designer / copyright | Licence evidence | File in repo | Size |
|---|---|---|---|---|---|
| DM Sans | OFL 1.1 | The DM Sans Project Authors (Colophon Foundry), https://github.com/googlefonts/dm-fonts | `license: "OFL"` in https://github.com/google/fonts/blob/main/ofl/dmsans/METADATA.pb; text at https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt | `public/fonts/dm-sans-latin-variable.woff2`, `public/fonts/OFL-DM-Sans.txt` | 62,724 B |
| Fraunces | OFL 1.1 | The Fraunces Project Authors (Undercase Type), https://github.com/undercasetype/Fraunces | `license: "OFL"` in https://github.com/google/fonts/blob/main/ofl/fraunces/METADATA.pb; text at https://github.com/google/fonts/blob/main/ofl/fraunces/OFL.txt | `public/fonts/fraunces-latin-variable.woff2`, `public/fonts/OFL-Fraunces.txt` | 67,304 B |

Source of the WOFF2 files: the official Google Fonts delivery for these two families (the same files the site loaded before, fetched from the Google Fonts CSS API `https://fonts.googleapis.com/css2?family=DM+Sans:opsz,wght@9..40,400;9..40,500;9..40,600&family=Fraunces:opsz,wght@9..144,400;9..144,500;9..144,600`, which points to `https://fonts.gstatic.com/s/dmsans/v17/rP2Hp2ywxg089UriCZOIHQ.woff2` and `https://fonts.gstatic.com/s/fraunces/v38/6NU78FyLNQOQZAnv9bYEvDiIdE9Ea92uemAk_WBq8U_9v0c2Wa0KxC9TeA.woff2`). Google already serves these as the **latin subset** (the `/* latin */` block), so no further subsetting was done and no glyph the site used before is lost (U+0000-00FF, typographic punctuation, euro, trademark, minus). Each file is a variable font covering weights 400 to 600 (the weights the site used); Fraunces keeps its optical-size axis. The Vietnamese and latin-extended blocks were not downloaded (unused; they were never fetched by visitors with English text either, because of `unicode-range`).

Implementation: `@font-face` rules with `font-display: swap` in `src/styles.css`; `<link rel="preload" as="font" crossorigin>` for both files in `src/routes/__root.tsx`; the Google Fonts stylesheet and the two preconnects were removed, so no third-party font request remains (a privacy benefit for visitors as well).

Notes for a buyer: to update a font, replace the WOFF2 file (keep the file name or change it in `src/styles.css` and `__root.tsx`). Fonts in `public/` are served with Netlify's default revalidating cache headers; moving them to `src/assets` (hashed, `immutable`) would let repeat visits skip revalidation (optional follow-up, not done because it changes the asset pipeline).
